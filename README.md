# ДРЕЙФ — команда DevCore, Космический идеатон БРИКС 2026

**Что подаём.** Кейс 3 «Моделирование полёта и расчёт траекторий». Буксир «СКАУТ» компании А-РОКЕТС развозит спутники после попутного запуска. ДРЕЙФ считает, выполнима ли заявка клиента, за сколько суток и сколько ксенона уйдёт. Слайды: `out/slides/DREIF_portfolio.pdf`, редактируемая версия `out/slides/DREIF_portfolio.pptx`. Подача 25.10 до 23:59.

## Почему кейс 3. Оспорьте, если не согласны
1. **Это задача самого партнёра.** А-РОКЕТС продаёт «перевод МКА на целевые орбиты с различными наклонениями и высотами» и сравнивает себя с конкурентами по строке «Время маневра, дн». Оспорь, если на их сайте этого нет: `work/src/arockets/strings.txt`.
2. **Задача не решается в лоб.** Повернуть плоскость орбиты на 15° двигателем стоит около 3,1 км/с, а у буксира с грузом 50 кг всего 2,0–2,8 км/с. Обход — дрейф плоскости из-за сплюснутости Земли: топлива мало, но уходят месяцы. Поэтому клиенту нужен выбор «срок или ксенон». Оспорь: `python3 work/calc/scout_first_calc.py`.
3. **Модель проверяется на реальных спутниках.** У 72 спутников OneWeb модель по истории высоты и наклонения восстановила поворот плоскости на 64–123° с ошибкой меньше 0,3°. Оспорь: `work/kaggle/oneweb_drift/RESULTS.md`.

Запасной вариант был кейс 1: камера буксира определяет положение чужого спутника при сближении. Не взяли, потому что для камеры есть только синтетические снимки, а сближение — побочная задача буксира. Подробно: `out/DECISION.md`.

## Что исправили после проверки командой
Антон нашёл три ошибки (`out/TECHNICAL_REVIEW.md`):
- в выборку OneWeb попали две ступени ракеты: было 74 объекта и ошибка до 0,47°, стало 72 спутника и 0,29°
- «модель предсказала» заменили на «восстановила по известной истории»: это проверка эффекта, а не прогноз миссии
- «за 60 суток невыполнимо» заменили на «в рассмотренных стратегиях решения нет»: на орбите «рассвет — закат» 60 суток хватает (`work/calc/dawn_dusk_60.py`)

## Чего у нас пока нет
- **Подтверждённого заказчика.** А-РОКЕТС — кандидат для пилота, его участие не подтверждено. План проверки спроса: `out/PILOT_PLAN.md`, рынок и заменители (GMAT, Tudat, Orekit, свои скрипты баллистика): `out/MARKET_FIT.md`.
- **Новизны метода.** Дрейфовые орбиты для нескольких клиентов уже описаны (Apa, Hudson, Romano, 2026), Exotrail лицензировал ExoOPS внешним организациям. Наш вклад — открытый проверяемый расчёт под «СКАУТ».
- **Цены миссии.** Ксенон — не цена: чем дольше миссия, тем дольше занят буксир.

## Как запустить расчёты
Нужен только Python 3.
```
python3 work/calc/scout_first_calc.py          # стратегии развоза и бюджет буксира
python3 -I work/calc/numeric_check.py          # численная сверка подъёма орбиты, около 1 с
python3 -I work/calc/strategy_map.py           # сколько ксенона стоит каждый срок
python3 -I work/calc/price_numeric_check.py    # численная проверка слайда 2, около 30 с
python3 -I work/calc/dawn_dusk_60.py           # 60 суток при тени и без тени, около минуты
python3 -I work/kaggle/oneweb_drift/summarize_payloads.py   # выборка OneWeb без ступеней
python3 -I work/tools/make_charts.py           # графики для слайдов
python3 -I work/tools/build_deck.py --pdf      # слайды в HTML и PDF (нужен Chrome)
python3 -I work/tools/build_pptx.py            # редактируемая версия слайдов (нужен python-pptx)
```
Задание на Kaggle запускается из `work/kaggle/oneweb_drift/` командой `kaggle kernels push -p .` (нужен свой токен Kaggle и свой ник в поле `id` файла `kernel-metadata.json`).
